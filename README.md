# Travel Route Card

A standalone static travel route graphic generator.

## Publish with GitHub Pages
1. Create a **public** repository named `travel-map` on GitHub.
2. Upload the four files in this folder to the repository root (`index.html`, `manifest.webmanifest`, `icon.svg`, `sw.js`).
3. Go to **Settings → Pages → Build and deployment** and select **Deploy from a branch**, branch `main`, folder `/(root)`. Save.
4. Wait for the Pages deployment, then open `https://YOUR-USERNAME.github.io/travel-map/`.
5. On iPhone Safari, choose **Share → Add to Home Screen**.

City names must match suggestions. All drawing is local, and no personal trip data is uploaded.
